# IBM HR Data Profiling

## Project Overview

This project demonstrates the data profiling process on the IBM HR Employee Attrition dataset using Python and Pandas.

## Objectives

- Explore the dataset
- Identify missing values
- Detect duplicate records
- Perform data profiling
- Create a Data Dictionary

## Technologies Used

- Python
- Pandas
- Google Colab
- GitHub

## Dataset

IBM HR Analytics Employee Attrition Dataset

## Project Workflow

1. Dataset Exploration
2. Missing Value Analysis
3. Duplicate Detection
4. Data Profiling
5. Data Dictionary Creation
6. Conclusion

## Outcome

The dataset was successfully explored, profiled, and documented, making it ready for future analysis or machine learning applications.
